# Research

**The evidence behind the twelve claims.** Each file here records what a body of work says and which claims of the [Constitution](../01-foundation/00-tcg-constitution.md) it backs. The argument is in the Constitution. This directory says where it comes from.

Parent: [theory/](../) · Sibling: [01-foundation/](../01-foundation/)

## Where to start

**[00-reading-guide.md](./00-reading-guide.md)** maps each claim to the files that back it, and each file to its claims. This README does not repeat that list.

## Format

Each research file follows one shape:

- **Sources.** Authors, year, title, journal or publisher, and a link where one exists. A mark in parentheses says how far a source was read.
- **Abstract.** What the work finds, in a few sentences.
- **Key claims.** What the work establishes.
- **Supports in TCG.** Which claim the work backs, cited by number, with one line on the connection.
- **Quotes and statistics.** A pointer. Citable passages live in [`publishing/02-tools/source-quotes.md`](../../publishing/02-tools/source-quotes.md), and every number has a row in the audit below.

Research files keep the economists' words where they discuss a paper: *specific* for what the Constitution calls built-in, and Dahlman's names for his three costs.

## Quality control

- **[audits/citation-provenance-audit.md](./audits/citation-provenance-audit.md)** traces every statistic a file cites to its primary source and records how far the trace goes. Check a statistic's status there before quoting it outside this repository.
